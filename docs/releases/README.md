# Releases

Production release manifests are generated by:

```powershell
pnpm release:manifest
```

The production deploy workflow writes manifests to:

```text
docs/releases/YYYY-MM-DD/production/release-manifest.json
docs/releases/YYYY-MM-DD/production/release-manifest.md
```

Each manifest records:

- Version.
- Environment.
- Commit and branch.
- Deployment URL.
- Rollback target.
- Release gate statuses, including database, API, E2E, MCP, smoke, observability, security, feature flags, incident readiness, restore drills, performance, governance, and environment drift.
- Evidence artifact locations.

Keep release manifests with the GitHub workflow run and production release notes.
